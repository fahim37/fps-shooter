# Hollowmere identity

Created using the built-in image generation tool. The transparent emblem is installed at `public/brand/hollowmere-emblem.png`; the matching multi-resolution browser icon is `app/favicon.ico` (16, 32, 48, 64, 128 and 256 px) and the home-screen icon is `app/apple-icon.png` (180 px). Assets were resized and encoded from the same generated artwork for consistency.

Generation prompt:

> Create a premium esports game brand emblem for HOLLOWMERE, a grounded multiplayer village and city combat shooter. Asset: a single standalone square emblem, transparent background, no text or wordmark. Bold highly legible angular H monogram formed by two symmetrical dark forest-green armored pillars and a sharp acid-lime connecting bridge, subtle negative-space downward spear/chevron in center, restrained chamfered shield outline. Clean professional flat vector-like silhouette with very subtle metallic edge depth, lime #d5f575 and charcoal green #14251c. Strong simple geometry readable at 16px, no tiny details, no gradients outside mark, no glow, no weapons, no skulls, no mockup, no surrounding scenery, no watermark. Emblem fills about 85% of canvas centered. Intended for website logo and favicon on dark tactical UI.
